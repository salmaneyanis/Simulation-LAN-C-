# 💻 Simulation-LAN-C

## 🇫🇷 Présentation
Projet en **langage C** simulant le fonctionnement d’un **réseau local (LAN)**.  
Il modélise l’échange de paquets entre plusieurs machines avec gestion de la **latence**, de la **bande passante** et des **files d’attente**.  
Objectif : analyser le comportement du réseau et mesurer les **performances** (latence, pertes, débit).

## 🇬🇧 Overview
A **C project** simulating the behavior of a **Local Area Network (LAN)**.  
It models packet exchanges between multiple nodes, taking into account **latency**, **bandwidth**, and **queue management**.  
Goal: analyze network behavior and measure key **performance metrics** such as latency, loss, and throughput.
